# Sk Raj Ali Portfolio

Personal portfolio website for Sk Raj Ali, Software Engineer and SDET. The site highlights experience, skills, education, projects, contact information, and a downloadable CV.

## Features

- Responsive single-page portfolio layout
- Animated hero section with typing text and particle canvas
- Custom cursor, scroll progress, reveal animations, counters, and interactive project cards
- Skills, experience, education, projects, and contact sections
- Downloadable CV from `assets/cv.pdf`
- Static HTML, CSS, and JavaScript with no build step

## Project Structure

```text
.
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── cv.pdf
│   └── profile.jpg
├── DSCF2140.JPG
└── Sk_Raj_Ali_CV_2026.pdf
```

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static server.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
